# Release v1.0.0 — 诗词飞花令首个正式版

> 发布日期：2026 年 10 月
> 标签：`v1.0.0` · `first-release`

## 🎉 首个版本

和电脑玩飞花令：你说一句含令字的诗，电脑接一句，接不上的一方落败。

## ✨ 功能

### 游戏核心
- **飞花令人机对战**：25 个可选令字（月、花、春、山、风……含"夏""冬"等冷门字）
- **智能应答**：电脑从诗库实时检索含令字的诗句，从不重复，永远不累
- **连击计分**：答对 +10 分，连击每次额外 +2
- **真实感设计**：电脑有 12% 概率"卡壳"，保证有输有赢
- **提示系统**：想不起来时，可请求半句提示

### 数据
- **3,067 句诗词**，全部清洗为简体：
  - 唐诗约 2,530 句（《唐诗三百首》+ 名篇）
  - 宋词名句 202 句（苏轼、李清照、辛弃疾、柳永、岳飞等）
  - 部编版小学必背古诗 143 句
  - 诗经、汉乐府、曹操、陶渊明 85 句
- **三个数据质量修复**：去除 77 处校勘注解；拆分 114 处整段诗；繁转简（否则搜"风"查不到"風"）

### 两个版本
- 🌐 **网页版**：单文件 `index.html`（234KB），双击即玩，支持手机端，可部署 GitHub Pages 在线访问
- 🐍 **Python 桌面版**：`python/feihualing.py`，仅需标准库 tkinter，无需安装任何依赖
